# NAYRA — Pure Packaged Drinking Water (Static Website)

Single-page, fully responsive website built with **HTML + Tailwind CSS v4 + vanilla JS**.
The order/enquiry form sends the filled details straight to **WhatsApp** (no backend, nothing stored).

## Folder structure
```
nayra-website/
├── index.html              # Full page (all sections + SVG icon sprite + logo)
├── assets/
│   ├── css/style.css       # Compiled Tailwind (generated — don't edit by hand)
│   ├── js/config.js        # ⭐ EDIT THIS: domain, WhatsApp no., phone, email, products, prices
│   ├── js/main.js          # Form → WhatsApp, menu, animations, product render
│   ├── fonts/              # Self-hosted Poppins + Tiro Devanagari Hindi (OFL)
│   └── img/                # bottle.svg, jar.svg, favicon.svg, label images (+ .webp)
│       └── photos/         # Unsplash lifestyle photos (WebP) — see photos/CREDITS.md
├── src/input.css           # Tailwind source + brand theme (colours, fonts, components)
├── scripts/build-dist.mjs  # Builds dist/ and syncs SEO values from config.js
├── _headers                # Security/caching headers for Netlify / Cloudflare Pages
├── .htaccess               # Security/caching headers + HTTPS redirect for Apache (Hostinger/cPanel)
└── robots.txt, sitemap.xml # Generated by `npm run dist`
```

## Run locally
Use VS Code **Live Server** (or `python3 -m http.server`) and open the page over `http://`.
Opening `index.html` directly as a file works too, but the browser will log a harmless font-preload warning.

## Change content
- Domain, number, email, hours, products, prices, social links → `assets/js/config.js` only.
- Product photos (optional): put e.g. `assets/img/products/1l.png`, set `image: "assets/img/products/1l.webp"`
  in config.js — `npm run dist` converts PNG/JPG to WebP automatically (needs `brew install webp`).
- Text/sections → `index.html`.

## Build & deploy
```bash
npm install
npm run dev     # watch mode while editing
npm run dist    # minified CSS + syncs canonical/og/JSON-LD/sitemap/robots from config.js + creates dist/
```
Upload **only the contents of `dist/`** to the host (Hostinger/cPanel `public_html`, Netlify, Cloudflare Pages, Vercel…).
`dist/` contains: `index.html`, `assets/`, `robots.txt`, `sitemap.xml`, plus `.htaccess` / `_headers`
(security headers — each host simply ignores the file meant for the other).

## Performance notes
- In `dist/index.html` the CSS is inlined (saves a full network round-trip on slow mobile data).
  `npm run dist` automatically adds that exact CSS block's sha256 hash to the CSP in `index.html`,
  `_headers` and `.htaccess` — so never hand-edit CSS inside `dist/`; edit `src/input.css` and rebuild.
- No backdrop-blur / blend-mode / big CSS blur filters: they make scrolling janky on phones.
- Photos are lazy-loaded and sized for their slot; the hero background is low-priority.

## Security notes
- Strict Content-Security-Policy (no inline scripts, no third-party scripts/styles/fonts).
- All config values are escaped / inserted as text; social links must be `https://`; product images must be local.
- Visitor input is cleaned (control & bidi-override characters stripped, length-limited) before building the WhatsApp message.
- Google Map loads only when the visitor taps “Show map” (sandboxed iframe) — no Google cookies on page load.
- Nginx users: copy the headers from `_headers` into your `server {}` block with `add_header … always;`.
